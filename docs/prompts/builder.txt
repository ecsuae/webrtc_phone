Task index rules:

  - refresh the one-line summary so it matches the final state or next planned action
- Do not invent dates.
- Use dates from the task file first.
- If the task file does not contain a reliable date, use archive/history sources if available.

- docs/tasks/Index.md is a compact index, not a full history file.
